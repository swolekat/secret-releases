VRMBones

v0.3.0

I've worked with Chrispy_Taters for models for a while but he had an issue where the ear bones would sometimes just disappear. These earbones are important because I use LZ's ear and tail graphs for vnyan to add "ear and tail tracking". I had an idea: "what if we could have an app that could transfer those over". It morphed into being a lot more. I might add more to this project as I get feedback from my modellers.

  • It can copy and paste ear, tail, and butt bones from one vrm to another
  • It can create new tail/ear bones on models that don't have them.
  • It can add butt bones and physics to models that don't have them.
  • It can add bones to skirts for more realistic movement.
  • It can add bones to hair for more realistic movement.
